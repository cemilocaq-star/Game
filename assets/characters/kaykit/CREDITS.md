# KayKit Adventurers character models and animations

Kay Lousberg (KayKit), "KayKit - Character Pack: Adventurers", CC0 1.0 (Public Domain).
Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
License: https://creativecommons.org/publicdomain/zero/1.0/

- Rogue.glb: Rogue with all 76 animation clips (the clip library every character uses).
- RogueHooded.glb, Knight.glb, Barbarian.glb, Mage.glb: the same skeleton and bones; the animation tracks were removed from these
  copies to save space (the game plays Rogue.glb's clips on them). Mesh data and embedded textures are unchanged.
